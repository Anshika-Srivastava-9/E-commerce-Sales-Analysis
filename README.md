# E-Commerce Sales Analysis

A beginner-friendly Data Science project analyzing e-commerce sales data using **Python, Pandas, NumPy, and Matplotlib**.

## 📌 About the Project

This project focuses on understanding and analyzing e-commerce transaction data to identify patterns in **sales, profit, categories, regions, payment methods, shipping methods, and customer ratings**.

The project follows a basic Data Science workflow:

```text
Data Understanding
        ↓
Data Cleaning
        ↓
EDA
        ↓
Data Visualization
        ↓
Insights
```

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* Anaconda

## 🔍 What I Worked On

* Checked and cleaned missing values
* Removed duplicate records
* Converted date columns to datetime
* Cleaned and standardized categorical data
* Performed Exploratory Data Analysis (EDA)
* Analyzed sales and profit
* Studied category and regional performance
* Analyzed payment and shipping methods
* Created visualizations using Matplotlib
